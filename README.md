# UNREAD

An open blueprint for not being read. A speculative design project set in 2062, after a rogue AI announces it will remove people from its register using data from radar sensing and machine learning.

The site is a single scroll-driven page (`index.html`, three.js):

1. A body scanned by street cameras and radar
2. Protective garments that fly in and lock on
3. How metal reflects, loose strands scatter, carbon absorbs, and a stiff layer hides breathing
4. A street robot that can't tell who it is looking at
5. A visual kit of household materials and where to wear them

Open `index.html` in a browser, or serve the folder with any static server.
